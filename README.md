# Full-Stack Portfolio CMS & Blog Application

A full-stack web application built with **Laravel 11**, featuring complete user authentication, Eloquent database relationships, RESTful API endpoints, and automated test coverage.

---

## 🚀 Features

- **User Authentication:** Secure user signup, login, and dashboard session control.
- **Content Management (CRUD):** Authenticated users can create, read, update, and delete blog posts.
- **Database Relationships:** Eloquent `hasMany` and `belongsTo` relationship between `User` and `Post` models.
- **RESTful API:** Structured JSON API endpoints for post consumption.
- **Automated Testing:** Comprehensive PHPUnit feature tests for authentication, CRUD operations, and database integrity.

---

## 🛠️ Tech Stack

- **Backend:** PHP 8.2+, Laravel 11 framework
- **Database:** SQLite / MySQL
- **Frontend:** Blade Templating, Tailwind CSS
- **Testing:** PHPUnit / Pest
- **Version Control:** Git & GitHub
